서불리 시티 통합 수정본 (원본 저장소 전체 포함)

이번에 실제 반영한 사항:
1. 보행 NPC 수 46 → 42명으로 변경
2. 사망한 NPC가 25초 후 신원/직업을 유지하며 기존 활동 지역에서 부활하도록 변경
3. 방탄조끼를 한 번의 피해를 막고 소모되는 방식으로 변경
4. 상점 방탄조끼 설명 변경
5. 원본의 동물, 직업, 경찰, 계정, 캐릭터, 멀티플레이 코드 유지

주의: 이 파일은 요청한 모든 기능의 완성본이 아닙니다.
NPC 차량 탑승/클럽/카지노/병원 방문의 완전한 일상 AI, 시작시 키/몸무게/얼굴 커스터마이징 UI, 새로운 고해상도 3D 모델, 서버 보안 강화, 동물 표시 오류의 실제 기기 재현 및 수정은 완료되지 않았습니다.
기존에 이미 구현된 기능과 새로 추가한 기능을 구분해야 합니다.

설치: 압축을 풀고 Seobuly-city-main 폴더 안의 모든 파일과 폴더를 GitHub 저장소의 같은 경로에 업로드하세요. src/ 파일만 올리면 기존 index.html은 자동 갱신되지 않습니다. GitHub Actions가 main 브랜치 푸시 시 build.py를 실행해 배포하도록 설정되어 있습니다. 기존 계정 데이터/비밀키는 절대 ZIP에 넣지 마세요.
