서불리 시티 개선 패치 (2026-10-13)

구현:
- NPC 정원 50명
- NPC 원거리 재배치 시 기존 신원/의상/직업 유지
- 기존 사망 후 부활 동작 유지
- NPC 일상 활동 주기적 변경(직업에 맞춘 기존 활동 목록 내)
- 동물 표시 거리 확대(기존 동물 모델 및 생성 코드 유지)
- 여성 상체 의상 곡면 비율 개선(기존 절차형 3D 모델 기반)
- 서버 메시지 및 계정 입력 크기 제한, 저장 크기 제한, 응답 보안 헤더 추가

미완료/주의:
- 새로운 고해상도 3D 모델 에셋 전체 교체는 하지 않았음
- 동물 표시 오류의 모든 원인을 실제 모바일에서 재현/검증하지 못함
- NPC 차량 운전/시설 내부 방문의 완전한 자율 AI 구현은 아직 아님
- 서버는 여전히 클라이언트 호스트를 신뢰하는 구조이므로 치트 방어 완성 아님
- 서버 수정은 Cloudflare Worker를 별도 배포해야 적용됨
- 원본 백업 후 전체 폴더 내용을 GitHub에 반영할 것
