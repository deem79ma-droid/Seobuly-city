# 서벌리 시티 3D

브라우저 오픈월드 멀티플레이 게임 (Three.js + PeerJS, 2인 P2P).

▶ 바로 하기: https://deem79ma-droid.github.io/Seobuly-city/

## 친구랑 같이하기 (버튼 하나)
- **👫 친구랑 같이하기**: 방이 바로 만들어지고 초대 링크 창이 뜹니다 → **📋 링크 복사** / **📤 공유하기**로 카톡·문자에 붙여넣기
- 친구가 링크(`...?room=코드`)를 누르면 **5초 뒤 자동 참가** (바로 들어가려면 **👉 바로 참가하기** 버튼, 외형을 먼저 꾸미려면 "잠깐, 외형부터 꾸밀래요")
- **⚡ 빠른 참가**: 공개방(PUB01~PUB08) 중 사람이 기다리는 방에 들어가고, 없으면 내가 공개방을 엽니다
- 혼자 하다가도 `P` 휴대폰 ▶ **🔗 친구 초대 링크** 를 누르면 그 자리에서 방이 열립니다
- 방장이 나가거나 연결이 끊기면 같은 방 코드로 자동 재접속 / 방 이어받기를 시도합니다 (같은 링크로 다시 들어오면 됨)

## 택시 (진짜로 타고 이동)
- `P` 휴대폰 ▶ **🚕 택시 호출** → 목적지(16개 구역)를 고르면 택시가 내 근처 도로로 옵니다 (지도·미니맵에 🚕 표시)
- 택시 옆에서 `E` **내 택시 타기** → 뒷자리에 앉고 카메라가 택시를 따라갑니다
- AI 기사가 도로망에서 **A\* 최단 경로**로 차선을 따라 운전합니다 (코너 감속, 앞차 감지, 막히면 후진/우회). 경로는 지도에 표시
- 도착하면 자동으로 내려주고 요금이 빠집니다 (기본 3,000원 + km당 1,200원)
- 가는 중에 `E` **세워주세요** → 그 자리에 정차하고 거리만큼 요금 정산. 타고 있는 중에 휴대폰에서 목적지 변경 가능
- 길에 다니는 빈 택시는 `E` **택시 잡기**로 세워서 탈 수 있고, `F`는 예전처럼 탈취
- 멀티플레이에서도 택시 위치·탑승 상태가 상대 화면에 동기화됩니다

## 관리자 모드
- 로비의 [관리자] 칸에 비밀번호를 넣고 입장하거나, 게임 중 `F2`(또는 채팅 `/admin`)로 로그인
- **관리자가 들어오면 승인 없이 무조건 방장 권한을 가져옵니다** (방을 만든 사람이 누구든). 관리자 메뉴의 **👑 방장 권한 가져오기**로 다시 요청 가능
- 관리자는 추방/밴 불가, 무한 돈·탄약, 전 무기, 정장+선글라스, 체포 면제, 경찰/의사 즉시 응대, 16개 구역 순간이동
- **방장은 관리자 비밀번호를 절대 알 수 없습니다**: 비밀번호는 관리자 브라우저 밖으로 나가지 않습니다.
  - 비밀번호 → PBKDF2(15만 회)로 Ed25519 개인키 생성 (내 브라우저 안에서만)
  - 게임 파일에는 **공개키만** 들어갑니다
  - 방장이 매번 새 난수(챌린지)를 보내면 관리자가 서명만 돌려주고, 방장은 공개키로 서명을 확인합니다 → 서명은 그 방·그 순간에만 유효해서 재사용 불가
- 비밀번호는 GitHub Secret `ADMIN_PW` 로만 주입됩니다 (저장소의 `index.html`에는 관리자 키가 없고, 배포할 때 Actions가 공개키를 넣음). 공개키로부터 비번을 무차별 대입할 수는 있으니 **길고 추측 어려운 비밀번호**를 쓰세요.

## 배포 (GitHub Pages)
1. 저장소 Settings → Pages → Source: **GitHub Actions**
2. (선택) Settings → Secrets and variables → Actions → `ADMIN_PW` 시크릿 → 관리자 모드 활성화 (없으면 비활성)
3. `main`에 push 하면 자동 빌드·배포. 주소: `https://<계정>.github.io/<저장소>/`

## 로컬 빌드
- `python3 build.py` → `index.html` (관리자 모드 꺼짐)
- `ADMIN_PW=비번 python3 build.py` → 공개키만 들어간 `index.html` (비번·개인키는 파일에 안 들어감). `ADMIN_PUB=<공개키 hex>`로 직접 넣어도 됨
- 테스트용 주소 옵션: `?local=1` (같은 브라우저 탭 두 개끼리 연결), `?peerhost=localhost&peerport=9000&peersecure=0` (자체 PeerJS 서버)

## 한계
- 최대 **2명** (P2P 직접 연결)
- 연결 중개에 PeerJS 공개 서버(0.peerjs.com)를 씁니다. 서버가 느리거나 막히면 접속이 안 될 수 있음
- TURN 중계 서버가 없어서, 일부 회사/학교 망·통신사 NAT(특히 둘 다 모바일 데이터)에서는 연결이 안 될 수 있습니다 → 와이파이로 바꿔 보세요
- 브라우저 탭이 백그라운드로 가면 느려지거나 30초 뒤 연결이 정리될 수 있음
- 방장이 나가면 남은 사람이 방을 이어받지만, 그동안의 일부 상태(NPC 위치 등)는 다시 만들어집니다
